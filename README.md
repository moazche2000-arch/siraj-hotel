# فندق السِّراج

لعبة إدارة فندق مسكون بالجن عام ١٩٧٨، بالعربية ومنظور ثنائي الأبعاد. تبدأ مالكًا للفندق ومعك ١٠٠ ر.س وغرفة واحدة فارغة. اشترِ أثاثًا، وسكّن المسافرين، واستخدم دخل الإقامات لتوسّع الفندق.

## اللعب

- [العب من المتصفح](https://moazche2000-arch.github.io/siraj-hotel/) أو [حمّل أندرويد](https://github.com/moazche2000-arch/siraj-hotel/releases/download/v2.1.0/siraj-hotel-android.apk).
- خلِّ الجوال بالعرض واسحب بإصبعك وثبّته للمشي. ارفعه للتوقف. اضغط ضغطة قصيرة قرب باب غرفة أو مكتب الاستقبال للتفاعل. ترى المنطقة التي تمشي فيها فقط، ويستغرق التلاشي عند دخول منطقة ثانية نحو ٠٫٣ ثانية.
- الأيقونات الأربع تفتح الإعدادات والضيوف ودفتر الأعمال والمتجر. لإغلاق اللوحة اضغط الأيقونة نفسها أو علامة ✕ أو المس خارجها. تتوقف الحركة والساعة أثناء فتح لوحة.
- افتح الغرفة ١٠١ من المتجر، اختر خانة فارغة، واشترِ سريرًا. كل غرفة لها ست خانات. كل نوع أثاث له سعر وقيمة راحة بدرجتين من الجودة.
- الضيوف ينتظرون عند الاستقبال. اختر ضيفًا ثم اسكنه في غرفة فارغة فيها سرير صالح، أو اعتذر له. يرتبط عدد الضيوف وميزانياتهم بسمعة الفندق.
- الضيف يقيم ليلتين إلى خمس ويدفع عند الخروج. الإيجار يتأثر براحة الأثاث والنظافة وحالته، ويُراعى سقف ميزانية الضيف. تقييمه يؤثر على السمعة.
- دفتر الأعمال يعرض سبب المهمة الحالية والغرفة التي تحتاجها. تظهر مهمة واحدة إلى أن تكمّلها أو تتجاهلها. اكنس وامسح في مهمة واحدة، أصلح قطعة أو بدّلها، أو عالج تسريبًا أو لمبة محروقة أو مفتاحًا ضائعًا.
- تتراكم الأوساخ تدريجيًا وتبدأ حماية مدتها ٩٠ ثانية لعب بعد التنظيف. يبدأ الجن في اليوم الثاني ويتخطّون الغرف المحمية والغرفة التي يقف فيها اللاعب.
- أكمِل طلب الضيف قبل موعده لتحصل على مكافأة. تقدر توظف عامل تنظيف من **التطويرات والفريق**، وتشتري العربة أو الأقفال أو تجهيزات الضيوف من القائمة نفسها.
- اليوم مدته ١٠٠ ثانية من اللعب الفعلي. يظهر ملخص الحساب تلقائيًا عند انتهاء الوقت. القوائم والمهام والإيقاف توقف عدّاد اليوم.

الحفظ تلقائي دوري وبعد التصرفات المهمة، ويمكن حفظ اللعب يدويًا من الإعدادات. صيغة الحفظ ٣ تحتفظ بتقدّم إدارة الفندق في 2.0.0 وتضيف مؤقتات الحماية والمهام وسرعة المشي. ينتقل حفظ الورديات إلى اليوم الأول مع الاحتفاظ بالرصيد بحد أدنى ١٠٠ ر.س والتطويرات وإعداد الصوت. **سجل الأخطاء** موجود في الترحيب والإعدادات.

## تعديل التوازن

القيم الأساسية موجودة في `game/settings.gd`.

| الإعداد | القيمة الافتراضية |
|---|---|
| `PLAYER_SPEED` | ٨٢٫٥ وحدة في الثانية |
| `SPEED_MULTIPLIERS` | سرعة هادئة ٠٫٨٢× وعادية ١× وأسرع ١٫١٨× |
| `CAMERA_ZOOM` و`CAMERA_FOLLOW_SPEED` و`CAMERA_FADE_SECONDS` | تكبير الممر ١٫٩٥× وسرعة تتبّع ٧ وتلاشي ٠٫٣ ثانية |
| `ROOM_CAMERA_MULTIPLIER` و`CAMERA_ROOM_MARGIN` | الحد الأعلى لتكبير الغرفة نسبة إلى الممر، وهامش ٢٢ وحدة في الشاشة المرجعية |
| `STARTING_CASH` و`DAY_SECONDS` | ١٠٠ ر.س و١٠٠ ثانية |
| `ROOM_PRICES` | ١٣٥، ٢٤٠، ٣٨٥، ٥٦٥، ٨٠٠ ر.س للغرف ١٠٢ إلى ١٠٦ |
| `ITEM_PRICES` و`ITEM_COMFORT` | أسعار وراحة الأثاث العادي والفاخر، درجتان متتاليتان لكل نوع |
| `MIN_STAY` و`MAX_STAY` | ليلتان إلى خمس |
| `REQUEST_DEADLINE` و`REQUEST_REWARDS` | ٣٢ ثانية ومكافآت ١٠، ١٤، ١٨ ر.س |
| `CLEANER_WAGE` و`CLEANER_INTERVAL` و`CLEANER_GAIN` | ١٧ ر.س يوميًا، تنظيف كل ١٨ ثانية، ١٨ نقطة نظافة |
| `BASE_NIGHTLY_RATE` و`COMFORT_RATE` و`CLEANLINESS_RATE` | أساس ٣٤ ر.س ومعاملان ٠٫٦٥ للراحة و٠٫١٧ للنظافة |
| `CLEAN_COOLDOWN` و`CLEANING_THRESHOLD` | حماية ٩٠ ثانية وحدّ طلب تنظيف عند انخفاض النظافة عن ٨٨ |
| `EMPTY_DIRT_PER_SECOND` و`OCCUPIED_DIRT_PER_SECOND` و`STAY_DIRT_PER_DAY` و`EVENT_DIRT_PER_SECOND` | معدّل الاتساخ في الغرفة الفارغة والمشغولة وأثر طول الإقامة وتراكم آثار الحوادث |
| `TASK_GAP` و`TASK_IGNORE_SECONDS` و`IGNORED_ROOM_COOLDOWN` | ٥ ثوانٍ بين العروض، و٠ يعني التجاهل اليدوي للمهام العادية، و٣٨ ثانية قبل إعادة العرض من نفس الغرفة |
| `HAUNT_FIRST_DAY` و`HAUNT_FIRST_SECOND` و`HAUNT_INTERVAL` و`HAUNT_ROOM_COOLDOWN` | اليوم الثاني بعد ٩٠ ثانية منه، ثم ٩٠–١٨٠ ثانية بين الحوادث و٢٢٠ ثانية لكل غرفة |
| `MAINTENANCE_FIRST_SECOND` و`MAINTENANCE_INTERVAL` | أول صيانة بعد ٦٠ ثانية، و٧٢ ثانية بين حوادث الصيانة |

## التطوير والنشر

افتح `project.godot` في Godot واضغط **F5**. صُيّرت الخريطة الخالية من الأثاث وأطالس الأثاث والضيوف في Blender. لإعادة تصييرها شغّل `blender --background --factory-startup --python-exit-code 1 --python art/render_hotel.py -- --management`.

أي دمج إلى `main` يشغّل تصدير الويب إلى GitHub Pages. نسخة أندرويد 1.3.0 والأحدث تبحث عن محتوى موقّع في GitHub Releases عند الفتح. للنشر صدّر `Android Content` ووقّع الحزمة من حساب Windows الذي يحتفظ بمفتاح توقيع المحتوى، ثم أرفق الحزمة وملف التوقيع بالإصدار الجديد. المراجعة ٨ مضمّنة في APK إصدار 2.1.0.

```powershell
godot --headless --path . --export-pack "Android Content" build/siraj-game.pck
.\tools\Sign-ContentPack.ps1 -Revision 9 -Tag v2.1.1
```

خط Noto Sans Arabic مرخّص بموجب SIL Open Font License، والنص الكامل موجود في `assets/OFL.txt`.
