# فندق السِّراج

لعبة ثنائية الأبعاد بالعربية في Godot 4.7.2. تبدأ كعامل خدمة غرف في فندق مسكون بالجن عام ١٩٧٨. بعد الوردية الثالثة يستقيل المدير ويسلّمك المفتاح، وتكمل العمل بصفتك المالك. دخل الغرف بعد المصاريف يدخل رصيدك، وتقدر تستخدمه لشراء تطويرات للفندق.

## اللعب

- [العب من المتصفح](https://moazche2000-arch.github.io/siraj-hotel/) أو [حمّل نسخة أندرويد](https://github.com/moazche2000-arch/siraj-hotel/releases/latest/download/siraj-hotel-android.apk).
- خلّ الجوال بالعرض عشان تظهر خريطة الفندق كاملة.
- اسحب بإصبعك على الشاشة في الاتجاه اللي تبغى تمشي فيه. تقدر تسحب بالماوس على الكمبيوتر.
- اقترب من علامة مهمة، ثم المس الشاشة أو اضغط زر المهمة. إذا سحبت إصبعك من جديد، تقدر تترك المهمة وتتحرك.
- لما تجهز الغرف، ارجع إلى مكتب الاستقبال والمس الشاشة لإنهاء الوردية.
- افتح تطويرات الفندق من دفتر الوردية بعد استلام الفندق.

التقدم ينحفظ تلقائيًا على الجهاز بعد كل مهمة. نسخة المتصفح تحتفظ بحفظها في بيانات الموقع.

## التطوير

افتح `project.godot` في Godot واضغط **F6** للمشهد المفتوح أو **F5** لتشغيل المشروع. إعداد **Web** يستخدم نمط Compatibility وتصديرًا دون تعدد المسارات.

## النشر على GitHub

إعداد GitHub Pages المطلوب هو **Settings → Pages → Build and deployment → Source → GitHub Actions**. بعد تفعيله، أي تحديث يُرفع إلى الفرع `main` يشغّل تصدير اللعبة وينشرها تلقائيًا على رابط Pages نفسه.

خط Noto Sans Arabic مرخّص بموجب SIL Open Font License، والنص الكامل موجود في `assets/OFL.txt`.
