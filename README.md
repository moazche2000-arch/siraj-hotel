# فندق السِّراج

لعبة ثنائية الأبعاد بالعربية في Godot 4.7.2. تبدأ كعامل خدمة غرف في فندق مسكون بالجن عام ١٩٧٨. بعد الوردية الثالثة يستقيل المدير ويسلّمك المفتاح، وتكمل العمل بصفتك المالك. دخل الغرف بعد المصاريف يدخل رصيدك، وتقدر تستخدمه لشراء تطويرات للفندق.

## اللعب

- [العب من المتصفح](https://moazche2000-arch.github.io/siraj-hotel/) أو [حمّل نسخة أندرويد ذات التحديث التلقائي](https://github.com/moazche2000-arch/siraj-hotel/releases/download/v1.5.0/siraj-hotel-android.apk).
- خلّ الجوال بالعرض. الكاميرا تتبعك في الممر، وتعرض الغرفة كاملة لما تدخلها.
- اسحب بإصبعك في اتجاه المشي وخله على الشاشة لمواصلة الحركة. ارفعه للتوقف. تقدر تستخدم الماوس بالطريقة نفسها.
- اقترب من علامة مهمة والمس الشاشة أو اضغط زر المهمة. امسح الغبار أو الماء بالسحب، وبدّل الفراش بالترتيب، وشدّ المسامير في توقيتها.
- لما تجهز الغرف، ارجع إلى مكتب الاستقبال والمس الشاشة لإنهاء الوردية.
- افتح تطويرات الفندق من دفتر الوردية بعد استلام الفندق.

التقدم ينحفظ تلقائيًا على الجهاز بعد كل مهمة. نسخة المتصفح تحتفظ بحفظها في بيانات الموقع. تقدر تفتح **سجل الأخطاء** من شاشة الترحيب أو من قائمة الإيقاف وتنسخ آخر ٢٠ حدثًا. على أندرويد ١١ والأحدث، تظهر أيضًا أسباب الإغلاق الأخيرة اللي سجّلها النظام إذا كانت متاحة.

تبحث نسخة أندرويد 1.3.0 والأحدث عن تحديثات المحتوى على GitHub عند فتحها مع اتصال بالإنترنت. تفتح آخر نسخة سليمة إذا تعذّر الاتصال أو فشل التحديث. إذا احتجت تثبيت ملف APK، ثبّته فوق النسخة الموجودة عشان يبقى حفظك. تحديث محرك Godot أو إعدادات تطبيق أندرويد يحتاج ملف APK جديدًا.

## التطوير

افتح `project.godot` في Godot واضغط **F6** للمشهد المفتوح أو **F5** لتشغيل المشروع. إعداد **Web** يستخدم نمط Compatibility وتصديرًا دون تعدد المسارات.

مشاهد الخريطة والعامل والجن موجودة في `art/siraj-hotel.blend`. لإعادة تصيير الصور المستخدمة في اللعبة، شغّل `blender --background --factory-startup --python-exit-code 1 --python art/render_hotel.py`.

## النشر على GitHub

إعداد GitHub Pages المطلوب هو **Settings → Pages → Build and deployment → Source → GitHub Actions**. بعد تفعيله، أي تحديث يُرفع إلى الفرع `main` يشغّل تصدير اللعبة وينشرها تلقائيًا على رابط Pages نفسه.

لنشر تحديث محتوى أندرويد، صدّر الحزمة بإعداد **Android Content** ووقّعها من حساب Windows الذي يحتفظ بمفتاح توقيع المحتوى. استخدم رقم مراجعة أعلى من آخر إصدار. المراجعة 6 مضمّنة في إصدار 1.5.0. أرفق الحزمة وملف التوقيع بأحدث إصدار على GitHub Releases، بنفس الوسم المستخدم للتوقيع. حدّث رابط التحميل هنا عند نشر APK جديد.

```powershell
godot --headless --path . --export-pack "Android Content" build/siraj-game.pck
.\tools\Sign-ContentPack.ps1 -Revision 7 -Tag v1.5.1
```

خط Noto Sans Arabic مرخّص بموجب SIL Open Font License، والنص الكامل موجود في `assets/OFL.txt`.
